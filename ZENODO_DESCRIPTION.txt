DESCRIPTION
Data supporting “Controlling water–hydroxyl resonance on dual-atom site catalysts.” The manuscript analyzes 1,659 intact OH–H₂O co-adsorption structures and 154 single-water reference structures, with available corresponding bare catalysts. The systems contain Cr–Cu metal centers, B1/B2 base fragments, N/O/S bridges, and A1, A2, A4, A5, A6, or A9 acid fragments.

The release provides RPBE-D4-optimized geometries, frozen-fragment interaction-energy components, filtering metadata, available Bader net charges and atomic magnetic moments, and standard ASE calculator results where present. Each dataset is supplied in equivalent ASE SQLite (.db) and ASE JSON (.json) formats. README and data-dictionary files describe methods, provenance, units, atom indexing, cross-file identifiers, and missing-data handling. The accompanying resonance_analysis.ipynb performs the analysis and generates Figures 2–4 and SI2–SI7; Figure 1 and SI1 are prepared separately.
